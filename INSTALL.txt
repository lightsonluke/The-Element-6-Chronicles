MATCH SCREEN BACKDROP REPLACEMENT — SIDE UPDATE

Files included:
- GameCanvasPortal.jsx
- VolleyballCanvasPortal.jsx
- index.css

Install:
1. Back up the three matching files in your existing project.
2. Copy these files into the project root, replacing the existing files.
3. Restart the dev server / rebuild the game.

What this changes:
- While a normal match canvas is mounted, its full-screen host is an opaque dark gameplay surface. The menu/page backdrop no longer shows through around the 16:9 match canvas.
- Volleyball uses the same active-match backdrop behavior through its separate canvas host.
- The opaque surface is marked active only during a match and is cleared when the portal unmounts, so it should not stay over menus after leaving a match.
- Pause controls and other React match UI are not moved or removed.

This is a focused source patch. It has not been verified in live browser gameplay in this environment.
