Element 6 — single-stage Split City and articulated character package

Upload all archive contents to the matching project-root paths.

This package replaces prior Split City packages. It uses only the supplied
neon-crystal-floating-stage.png for the playable platform; platform-left.png
and platform-right.png are not used.

The platform is drawn once behind fighters and a clipped front-lip pass is
drawn after fighters. Collision is 45px below the visible top, so feet and
lower shins appear embedded in the stage rather than floating over it.

The stage has one playable top surface plus invisible underside segments that
trace the visible crystal hull and corners. These segments are physics-only;
they never draw generic blocks on the supplied artwork.

Characters retain their existing design and full size. Arms and legs use
continuous two-bone motion with visible elbow/knee crease lines. Running,
jumping, attacks, hitstun, and emotes use the same continuously calculated
limb angles—no sprite-frame swapping is used.
