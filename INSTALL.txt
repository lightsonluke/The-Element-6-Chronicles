Element 6 — Split City rebuild replacement package

Upload every file in this archive to the matching project-root path. Keep the
public/art/stages/split-city folder intact.

This package deliberately replaces the earlier Split City/character packages.
It does not use the old generic metal platform, elevated ledges, decorative
side props, or a sprite-sheet crop renderer.

The stage uses the two supplied platform files independently:
  platform-left.png  -> left side of the joined stage
  platform-right.png -> right side of the joined stage

They are drawn directly edge-to-edge with a 2px seam overlap in renderer.js.
The one collision rectangle in PlatformFighter.jsx, OnlineFight.jsx,
CustomRoomGame.jsx, and rollback/element6Simulation.js is embedded 8px below
the visible top surface, so fighters stand visually inside the platform rather
than floating on top of it.

Character rendering keeps the original full gameplay scale and silhouette,
with no eyes. Arms and legs now use two same-colour, rounded connected segments
with an elbow/knee bend; idle pose remains still. fighter.js uses the matching
original-scale collision envelope.
