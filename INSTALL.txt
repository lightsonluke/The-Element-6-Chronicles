RESONANCE CONSTRUCTS PATCH INSTALLATION

1. Make a backup of the existing project files listed in this ZIP.
2. Extract the ZIP into the existing project root and overwrite matching files.
3. Run:
   node --test resonanceConstructs.test.mjs resonanceConstructsAnimation.test.mjs resonanceConstructsAudit.test.mjs
4. In an environment with the project's dependencies installed, run:
   npm run build

The tests need the existing project modules imported by renderer.js; they are not standalone tests from inside the ZIP folder.
See ANIMATION_VERIFICATION_REPORT.md for results and known verification limits.
