# Element 6 — Part 21 Story Mode Replacement

This package upgrades the existing Story Mode into the detailed five-book adventure layer requested for Part 21.

## Included
- Five Story Mode save slots.
- A direct STORY MODE button on the main menu.
- Detailed, data-driven scenes for all five Books.
- Scene-specific backdrops, architecture, landmarks, platforms, weather, hazards, NPCs and dialogue.
- Story shops using Residue so purchases do not alter the main-game coin economy.
- Existing roster characters remain the real playable/boss characters whenever they exist.
- Missing lore bosses use temporary combat definitions that reuse the existing fighter renderer/engine rather than adding permanent roster characters.
- Existing StoryBattle/fighter engine remains the combat system.
- The five-book progression, canon-locked events and existing story data remain intact.

## Important
This is a replacement-file package, not a whole-project replacement. Copy the files into the project root and overwrite matching files.
